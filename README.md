# 星河名利场：娱乐圈模拟器

一个纯前端娱乐圈文字模拟器原型，直接打开 `index.html` 即可游玩。

## 已包含

- 开局自定义姓名、性别、家境。
- 40 个优势，开局选择 5 个，每个都有不同属性加成。
- 每日行动与每日突发事件，包含粉丝事件、私联传闻、包养邀约、地下恋爱、堕落路线、家庭触发等。
- 每 3 天随机弹窗事件，需要做选择并改变属性。
- NPC 系统：头像立绘、性格、性取向、偏好、好感、信任、张力。
- 今日 NPC 每天随机刷新；只有特别关注后才能长期聊天。
- 每个 NPC 有人生轨迹，可在特别关注界面查看共同经历。
- 特别关注界面：聊天、做爱、送礼物、要礼物、吃饭、要资源、NP 剧情等互动。
- AI 对话 API 设置界面：前三个本地选项，第四个选项调用 OpenAI 兼容 API，并带入 NPC 性格和关系数值。
- 首页只保留行动体验，人物资料独立到“资料”页。
- 子女系统：共同育儿、辅助生育、代孕协议、资质、人物模板、随机优势、成长方向、培养。
- 传代系统：可选择孩子继承娱乐圈路线，成为星二代继续游戏。

## 使用方法

1. 打开 `index.html`。
2. 创建角色并选择 5 个优势。
3. 在 `API` 页填写接口地址、模型名和 API Key。
4. 在 `AI 对话` 页先看三个本地选项；不满意时输入内容并点击“调用 API”。

## 内容边界

游戏包含成人娱乐圈、舆论、权力关系、NP 张力和亲密关系，但所有 NPC 浪漫互动均按成年人、自愿、非露骨、尊重边界处理。子女系统只涉及成长、教育、职业与传承。
